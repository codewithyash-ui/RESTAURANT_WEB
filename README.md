# 🍞 Golden Crust Bakery - Complete Bakery Shop Website

A full-stack bakery e-commerce website with responsive design, shopping cart, dummy payment, order management, and admin dashboard.

## ✨ Features

- **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- **Beautiful Animations** - Smooth transitions, hover effects, and scroll animations
- **Product Gallery** - 6+ bakery items with images and descriptions
- **Shopping Cart** - Add/remove items, update quantities, persistent storage
- **Quick Order Page** - Direct ordering without validation
- **Dummy Payment** - No validation required, any card details work
- **Order Management** - Store orders in MongoDB database
- **Admin Dashboard** - View all orders placed
- **Multiple Pages** - Home, Menu, About, Contact, Cart, Checkout, Admin
- **Mobile Navigation** - Hamburger menu for mobile devices

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3 (Tailwind CSS + Custom Animations)
- Vanilla JavaScript (ES6)
- Font Awesome Icons

### Backend
- Node.js
- Express.js
- MongoDB with Mongoose

### Tools
- Nodemon (Development)
- CORS for cross-origin requests
- Dotenv for environment variables
